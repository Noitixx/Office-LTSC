# Intro

Hey! From here, you can install Microsoft Office using the Microsoft ODT *completely legally*.
I have included all the files necessary for the installation of:

*Office LTSC Professional Plus 2024
*Visio LTSC Professional 2024
*Project Professional 2024
 (all of them are Volume License)

The installation is strictly for 64-bit Windows 10 or 11; for 32-bit systems, you will need to follow the steps for "Changing the XML."
If you want to change your Office version, remove a program from the suite... follow the steps of "Changing the XML"

# Instructions 

Place all the contents (except for README.md) into a folder, open a terminal in that folder, and then run the command:
> setup /download configuration.xml

It may appear that nothing is happening, but the download is taking place in the background. Once the download is complete, the command prompt will return.
Then execute:
> setup /configure configuration.xml
